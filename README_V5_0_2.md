# Antonicelli — V5.0.2

Ajustes visuais incrementais sobre a V5.0.1, sem alteração de banco ou Supabase.

- Fonte **Inter** carregada via Google Fonts, com fallback para fontes do sistema.
- Logo quadrado da Antonicelli ampliado na sidebar escura, ocupando grande parte da largura útil do menu.
- Cabeçalho compacto/mobile voltou a usar o logo horizontal original com **26 px de altura**.
- Placeholder do seletor rápido alterado de “Selecionar responsável...” para **“Responsável”**.
- Botão **Excluir tarefa** convertido em ícone de lixeira com `title` e `aria-label`.
- Aumentado o espaçamento horizontal entre o seletor de status e avatar/seletor de responsável.

Nenhuma migração de banco é necessária.
