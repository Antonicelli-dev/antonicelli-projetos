# Antonicelli — Gestão de Eventos V2.9

## Ajustes visuais
- O logo oficial da Antonicelli passa a aparecer no cabeçalho do sistema.
- O texto "ANTONICELLI" foi removido do cabeçalho.
- Quando uma tarefa possui conteúdo no campo "Anotações", aparece um ícone 📝 ao lado do nome da tarefa.

## Banco de dados
Nenhuma alteração de banco nesta versão.
Use o mesmo Supabase e o mesmo `.env` da V2.8.

## Atualização
1. Extraia a V2.9.
2. Copie o mesmo `.env`.
3. `npm install`
4. `npm start`
