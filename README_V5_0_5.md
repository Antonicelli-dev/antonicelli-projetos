# V5.0.5 — CORRE

Atualização de identidade visual do sistema.

- O sistema passa a se chamar **CORRE — Central de organização de rotinas, responsáveis e eventos**.
- Menu lateral usa `logo-corre.svg`.
- Cabeçalho compacto/mobile usa `logo-corre-horizontal.svg` com 26 px de altura.
- Logo quadrado da Antonicelli foi movido para a parte inferior da sidebar, acima do usuário.
- Logo horizontal da Antonicelli aparece no rodapé das telas de Trabalhos, Minhas tarefas e da tela de tarefas de um trabalho.
- Nome do PWA atualizado para CORRE.
- Nenhuma alteração de banco de dados ou Supabase.
