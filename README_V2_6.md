# Antonicelli — Gestão de Eventos V2.6

Novidades:
- nome, status e responsável editáveis na janela de detalhes;
- datas e anotações mantidas;
- tarefas arrastáveis para reorganização;
- tarefas podem ser movidas entre categorias e fases;
- categorias de eventos existentes podem ser renomeadas;
- categorias do checklist-modelo podem ser renomeadas;
- edição de nomes das tarefas do modelo restaurada.

Permissões:
- administrador pode reorganizar a estrutura;
- colaboradores continuam podendo atualizar as tarefas conforme suas permissões.

Banco:
- usa o mesmo Supabase;
- nenhuma nova tabela;
- nenhuma coluna nova;
- dados existentes preservados.

Atualização:
1. Copie o mesmo `.env` da V2.5.
2. `npm install`
3. `npm start`
