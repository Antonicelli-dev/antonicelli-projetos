# V4.3.6 — Navegação superior compacta

Ajustes de interface:

- `Novo trabalho` continua como ação principal para administradores.
- `Calendário` e `Minhas tarefas` permanecem visíveis em telas largas.
- Em resoluções intermediárias, as duas ações viram botões compactos apenas com ícones e tooltip.
- `Modelos`, `Usuários`, `Arquivados` e `Lixeira` foram agrupados no menu **Mais**.
- Em telas mobile, `Calendário` e `Minhas tarefas` também passam para o menu **Mais**, reduzindo a ocupação horizontal.
- O título **Trabalhos em Andamento** tem prioridade de espaço e não é mais comprimido pela quantidade de ações.
- Nenhuma alteração de banco de dados ou Supabase.
