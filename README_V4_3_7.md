# Antonicelli V4.3.7

Atualização focada no ícone de instalação da plataforma como aplicativo/PWA.

## Alterações
- Adicionado `public/manifest.webmanifest`.
- Criados ícones PNG 192x192 e 512x512 a partir do SVG oficial já usado como favicon.
- Criado ícone maskable 512x512 para melhor adaptação em Android/Windows.
- Adicionados `manifest`, `apple-touch-icon`, `theme-color` e metadados de app no `index.html`.
- Nenhuma alteração no banco de dados, Supabase ou regras funcionais do sistema.

## Observação
Após publicar esta versão, desinstale um atalho/app antigo e instale novamente. Chrome/Edge podem manter o ícone anterior em cache.
