# Antonicelli — Gestão de Eventos V3.2

Os filtros de status, responsável e fase agora escondem:
- tarefas que não correspondem;
- categorias que ficaram sem tarefas visíveis;
- fases inteiras que ficaram sem categorias/tarefas visíveis.

Também funciona com filtros combinados.

Nenhuma alteração no banco de dados. Use o mesmo Supabase e o mesmo `.env` da V3.1.
