# Antonicelli V4.3.5

Correção pontual no editor visual:

- Links criados dentro de **Anotações das tarefas** e **Informações adicionais** agora podem ser abertos diretamente com um clique mesmo dentro do campo `contenteditable`.
- O endereço continua sendo validado pelos protocolos permitidos (`http`, `https` e `mailto`).
- O link abre em nova aba, preservando o conteúdo do editor.
- O cursor passa a indicar visualmente que o texto é clicável.

Não há alteração de banco de dados ou schema.
