# Antonicelli V5.0.1

Ajustes visuais sobre a V5.0, sem alterações de banco de dados.

- Sidebar desktop em cinza escuro, com navegação, estado ativo e perfil adaptados ao novo contraste.
- Cabeçalho mobile/recolhido no mesmo cinza escuro.
- Novo `logo-antonicelli-quadrado.svg` usado na navegação lateral e no cabeçalho mobile.
- Página interna de trabalho/tarefas mais compacta para acompanhar a densidade visual da nova lista de trabalhos.
- Cabeçalho do trabalho, metadados, filtros, fases, categorias, tarefas, status, responsáveis e ações tiveram dimensões e espaçamentos reduzidos.
- Ajustes responsivos preservam legibilidade e reorganizam os controles no mobile.
- Todas as funcionalidades, APIs, Supabase, PWA e dados da V5.0 permanecem inalterados.
