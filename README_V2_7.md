# Antonicelli — Gestão de Eventos V2.7

## Novidade principal
O botão global "+ Adicionar tarefa" foi removido do topo do evento.

Agora cada categoria possui:
- + Nova tarefa
- Renomear categoria

Ao usar "+ Nova tarefa":
- a fase já é definida automaticamente;
- a categoria já é definida automaticamente;
- o usuário informa apenas o nome da tarefa.

A tarefa é criada diretamente dentro da categoria escolhida.

## Banco de dados
Nenhuma mudança no banco.
Use o mesmo Supabase e o mesmo `.env` da V2.6.

## Atualização
1. Extraia a V2.7.
2. Copie o mesmo `.env`.
3. `npm install`
4. `npm start`
