# Antonicelli — Gerenciamento de Projetos V3.4

Alterações de nomenclatura:
- Gestão de Eventos → Gerenciamento de Projetos
- Eventos → Trabalhos em Andamento
- Editar checklist-modelo → Editar Modelos
- Novo evento → Novo trabalho
- Nome do evento → Nome do trabalho

As alterações são apenas de interface. O banco e as estruturas internas continuam compatíveis com as versões anteriores.

Use o mesmo Supabase e o mesmo `.env` da V3.3.1.
