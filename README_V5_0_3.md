# Antonicelli V5.0.3

Ajustes visuais incrementais sobre a V5.0.2.

- Padronizada a escala tipográfica da página de tarefas com a tela de Trabalhos.
- No mobile, responsáveis/avatares deixam de ocupar espaço na linha da tarefa.
- No mobile, a ação Excluir tarefa foi movida para um menu `...` no canto direito.
- Linha mobile reorganizada para priorizar nome da tarefa e status, reduzindo largura e overflow.
- Desktop preserva o botão de lixeira compacto já existente.
- Sem alterações de banco ou Supabase.
